什么是线程安全计数器

  普通计数器（线程不安全）：
  public class Counter {
      private int count = 0;

      public void increment() {
          count++;  // 看似简单，实际不是原子操作
      }

      public int getCount() {
          return count;
      }
  }

  问题： count++ 包含 3 个 CPU 指令（读→改→写），多线程下会互相覆盖：

  线程A: 读取 count=0
  线程B: 读取 count=0    ← A还没写回去，B也读到0
  线程A: 加1, 写回 count=1
  线程B: 加1, 写回 count=1    ← 覆盖了A的结果
  结果: count=1（应该是2）

  ---
  解决方案对比

  方案1：synchronized（最简单）

  public class Counter {
      private int count = 0;

      public synchronized void increment() {
          count++;
      }

      public synchronized int getCount() {
          return count;
      }
  }

  方案2：Lock（更灵活）

  import java.util.concurrent.locks.ReentrantLock;

  public class Counter {
      private int count = 0;
      private final ReentrantLock lock = new ReentrantLock();

      public void increment() {
          lock.lock();
          try {
              count++;
          } finally {
              lock.unlock();  // 必须放在 finally，确保释放
          }
      }

      public int getCount() {
          lock.lock();
          try {
              return count;
          } finally {
              lock.unlock();
          }
      }
  }

  方案3：volatile（只能保证可见性，不能保证原子性）

  public class Counter {
      private volatile int count = 0;  // 保证可见性，不保证原子性

      public void increment() {
          count++;  // ❌ volatile 不够！还是会出现线程安全问题
      }
  }

  volatile 的作用：
  - 线程修改变量后，其他线程立即看到新值（可见性）
  - 禁止指令重排序
  - 但不保证 count++ 这种复合操作的原子性

  方案4：AtomicInteger（推荐，兼顾性能和线程安全）

  import java.util.concurrent.atomic.AtomicInteger;

  public class Counter {
      private AtomicInteger count = new AtomicInteger(0);

      public void increment() {
          count.incrementAndGet();  // 原子操作，线程安全
      }

      public int getCount() {
          return count.get();
      }
  }

  ---
  测试验证（多线程压测）

  public class CounterTest {
      public static void main(String[] args) throws InterruptedException {
          Counter counter = new Counter();
          int threadCount = 100;
          int incrementPerThread = 1000;

          // 创建 100 个线程，每个线程加 1000 次
          Thread[] threads = new Thread[threadCount];
          for (int i = 0; i < threadCount; i++) {
              threads[i] = new Thread(() -> {
                  for (int j = 0; j < incrementPerThread; j++) {
                      counter.increment();
                  }
              });
          }

          long start = System.currentTimeMillis();

          for (Thread t : threads) t.start();
          for (Thread t : threads) t.join();

          long end = System.currentTimeMillis();

          int expected = threadCount * incrementPerThread;
          int actual = counter.getCount();

          System.out.println("预期: " + expected);
          System.out.println("实际: " + actual);
          System.out.println("结果: " + (expected == actual ? "✅ 线程安全" : "❌ 线程不安全"));
          System.out.println("耗时: " + (end - start) + "ms");
      }
  }
